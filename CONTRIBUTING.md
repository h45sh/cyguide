# Contributing to CyGuide

Thank you for your interest in contributing to CyGuide!

Please read our comprehensive **[Contributor & Developer Guide](docs/user/CONTRIBUTING.md)** for details on:

1. **[The Smart Adapter Architecture](docs/user/CONTRIBUTING.md#1-architectural-philosophy-smart-adapter--stupid-framework)**: How to write modular tool plugins under `tools/<name>/`.
2. **[Standard Schemas & PIKs](docs/user/CONTRIBUTING.md#3-standard-finding-schemas--primary-identity-keys-piks)**: Modeling findings and Primary Identity Keys.
3. **[Headless Development Workflow](docs/user/CONTRIBUTING.md#4-headless-first-development-workflow)**: Testing tools without TUI dependencies.
4. **[Tiered Protection & Governance](docs/user/CONTRIBUTING.md#5-code-governance--tiered-protection-policy)**: Review requirements for Core vs Adapter vs UI code.
5. **[Verification & Automated CI](docs/user/CONTRIBUTING.md#6-running-verification--continuous-integration)**: Running pytest and `./scripts/verify.sh`.
6. **[Code Standards & Ergonomics](docs/user/CONTRIBUTING.md#7-code-standards--developer-ergonomics)**: Ruff linting, formatting, and pre-commit hooks.
7. **[Conventional Commits](docs/user/CONTRIBUTING.md#8-pull-request--commit-standards)**: Commit message formatting and PR guidelines.
